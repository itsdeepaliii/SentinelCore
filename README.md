# SentinelCore Backend

Backend service for the SentinelCore project, built to manage authentication, APIs, database operations, and core business logic.

## Tech Stack
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- REST API

## Features
- User authentication and authorization
- Secure REST APIs
- Database integration
- Modular project structure

## Installation

```bash
git clone <repository-url>
cd SentinelCore-Backend
npm install
npm start
```

## Environment Variables

Create a `.env` file in the root directory and add the required environment variables.
